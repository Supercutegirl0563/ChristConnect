# 🏫 ChristConnect

> **Your school. Your opportunities. Your community.**

**CCS Connect** is a centralized digital school portal designed for **Christ Church Secondary School**. It brings school announcements, student applications, events, notifications, and other important school information into one convenient platform.

Instead of relying entirely on email for school communications, CCS Connect provides a dedicated space where students and teachers can interact with school information quickly and efficiently.

---

## ✨ Features

### 📢 Announcements

Teachers and school administrators can publish announcements for students.

* School-wide announcements
* Important notices
* Urgent announcements
* Categorized announcements
* Rich content and attachments
* Read/unread tracking
* Push notifications

### 📝 Applications

A dedicated application system for school opportunities.

Teachers can create applications for:

* 👑 Leadership roles
* 🤝 Student programmes
* 🏆 Competitions
* 🎤 Event committees
* 🌟 School ambassador roles
* 📚 Academic programmes
* 🎨 CCA leadership positions

Students can:

* Browse available applications
* Submit applications
* Track application status
* Receive results directly through the portal

Example application statuses:

`Submitted` → `Under Review` → `Shortlisted` → `Accepted / Rejected`

---

### 📅 Events

Students can easily see upcoming school events.

Events can include:

* School activities
* CCA events
* Competitions
* Important dates
* Meetings
* Programmes

---

### 🔔 Notifications

Students receive notifications for important updates.

Examples:

> 🔔 Your Student Council application has been shortlisted.

> 📢 A new school announcement has been posted.

> 📝 Applications for the 2027 Leadership Programme are now open.

---

### 👤 User Profiles

Different users have different permissions.

| Role              | Permissions                                                        |
| ----------------- | ------------------------------------------------------------------ |
| 👨‍🎓 Student     | View announcements, apply for opportunities, view own applications |
| 👨‍🏫 Teacher     | Create announcements, create applications, review submissions      |
| 🛡️ Administrator | Manage users, announcements, applications and events               |
| 🏫 School Admin   | Full administrative access                                         |

Students can only access their own application information.

## 🎯 Why ChristConnect?

Traditional email is useful for communication, but important school announcements can easily get buried among other emails.

CCS Connect is designed specifically for school communication.

### Gmail

* General-purpose email platform
* Announcements can get buried
* Difficult to organize school opportunities
* Application results may require separate emails
* Students may need to search through old messages

### ChristConnect

* 📢 Dedicated school announcement feed
* 📝 Built-in application system
* 🔔 School-specific notifications
* 📅 Centralized events
* 🔎 Easy searching and organization
* 🔐 Role-based access
* 🎓 Designed specifically for students and teachers

> **Gmail is an email system. CCS Connect is a school portal.**

## 🔐 Security & Privacy

ChristConnect is designed with student privacy in mind.

Important principles include:

* Role-based access control
* Students can only view their own applications
* Teachers can only access applications they are authorized to review
* Administrative actions require appropriate permissions
* Authentication through approved school accounts
* Secure storage of application information

> **Note:** This project is currently under development. Security measures should be reviewed and approved by the school before the system is used with real student data.
